# STITCH Clothing — Motion Studio

A static fashion frontend demo by Gampa Advaith, built with HTML, CSS and JavaScript.

Live demo: https://gampaadvaith2006.github.io/advaith-portfolio/stitch-clothing/

## Features
- Animated outfit transitions and a continuous garment runway.
- Draggable garments with spring motion and four patterns: vortex, orbit, float and wave.
- Scatter/reassemble, expanded studio view, keyboard garment controls, adjustable speed/intensity.
- Outfit comparison slider, demo fashion show, and device-local saved looks.
- Responsive layout, motion pause control and reduced-motion support.

## Run locally
From the repository root, run a static HTTP server, then open `/stitch-clothing/`.
No dependencies or build step are required. All asset references are relative for GitHub Pages project hosting.

## Demo scope
This is a visual frontend project, without payments, checkout, backend accounts or real cloth simulation. The cream sweatshirt and charcoal overshirt are AI-created outfit concepts. Saved looks use localStorage on the visitor's device.
